## 三、必须保留的「易被误删」信号

这些句子听起来像废话，实际是判断的骨架，**删了总结就空了**：

| 原话形态 | 为什么必须留 |
|---|---|
| 「这个位置我说的是阶段性反弹，不是中期底」 | 置信度边界，决定仓位 |
| 「指数波动不超过 2%，那不叫大跌」 | 作者自定义的判定标准，是整套逻辑的刻度 |
| 「像 7 月 24 号那一周」 | 历史类比 = 完整的情景预测，比任何形容词信息量都大 |
| 「卖方都建议配高股息，我不建议」 | 立场差异点，最强的可执行信息 |
| 「如果出现加速跌，那概率反而更大」 | 反向条件判断，容易被当成看空 |
| 「你不会选，就买对应 ETF 做定投」 | 分层建议，放弃选股的人的操作方案 |
| 「这个是左侧观察区，等右侧阳线再加」 | 时点纪律 |
| 「后面还有后手工具」 | 对政策节奏的预期，隐含后续催化剂 |
| 「中期低点可能还不在这」 | 明确的否定式预期，防止读者误判 |
| 「这个越讲越觉得不对了」 | 自我审查信号，内容缺失点，应标「未展开」 |

## 四、需要标注而非删除的内容

- **观众提问**：是问句，不是观点。作者未回答 → 不进总结；作者回答了 → 只写作者的回答。
- **自我修正 / 改口**：保留，标注「后修正为……」，这是判断演化的重要痕迹。
- **被打断的论述**：写「（此处中断，未展开）」。
- **敏感地带**：涉及具体政策、地缘、监管的表述，只做中性转述，不延伸、不评价、不猜测。
