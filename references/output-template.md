# 输出模板（抖音直贴版）

成品是**一篇粘进抖音编辑器就自带层次的短文章**，600~800 字（发图文）或 1000~1600 字（发文章）。

抖音编辑器不解析 Markdown，所以「好看」不靠语法，靠**留白 + 小标题 + 序号**。下面所有示例都是纯文本，粘进去长什么样就是什么样。

## 骨架（发图文，约 750 字）

```
标题（≤20 字）

开头两行：第一行给结论，第二行给位置。

（空一行）

一、小标题（≤12 字）

（空一行）

短段，1~2 句。

（空一行）

短段，1~2 句。

（空一行）

二、小标题

（空一行）

短段。

1、并列项一，一句话。
2、并列项二，一句话。
3、并列项三，一句话。

（空一行）

短段。

（空一行）

三、小标题

（空一行）

短段。

（空一行）

收尾一句，≤20 字。
```

节数 **3 节最稳，最多 4 节**，每节 3~5 个短段。

## 留白规范（"挤"的唯一解）

- 小标题：单独一行，前后各空一行。
- 段落：1~2 句，≤60 字，段间空一行。
- 列表：每项单独一行，项间**不**空行，列表前后各空一行。
- 每 2~3 段插一句单独成行的短句（≤15 字），当换气口。
- 一节不超过 5 段。

对比一下同样内容的两种排版：

```
挤版（不要）：
一、三个方向第一个是小市值加大容量这是主线也是最难拼手速拼交易能力不会选股就买指数基金定投第二个是抄社保三季度新加仓适合不会选小盘股的人社保帮你过基本面关缺点慢第三个是AI应用端细分资金在往小的地方走

松版（要）：
一、三个方向

第一个方向，小市值加大容量。这是主线，也是难度最大的。

拼手速，也拼交易能力。不会选股的，就买对应的指数基金做定投。

第二个方向，抄社保三季度的新加仓。适合不会选小盘股的人，社保帮你把基本面那道关过了，缺点是慢。
```

## 标题

固定为：

```
YYYY/MM/DD <主讲人>直播总结：<一句核心结论>
```

日期格式 `yyyy/MM/dd`，未给按上下文推断。主讲人未知用频道名。

- 发图文：整行 ≤20 字，结论要更短。例：`11/03 祝超：不再悲观，等右侧阳线`
- 发文章：≤30 字，可带完整结论。例：`2026/11/03 祝超直播总结：不再悲观，等一根右侧阳线`
- 若发「文章」，另写一行 ≤30 字的摘要放摘要框。

## 各节写法

### 开头（30 字内出结论）

不写"最近市场震荡加剧"这种铺垫。第一句给立场，第二句给位置感。

```
政策底已经出来了，市场底还没确认。他这次的态度很明确：不悲观了。

现在的位置，他说很像 7 月 24 号那一周，主跌段差不多走完。
```

### 一、先给整体判断

讲清：现在什么位置、凭什么这么判断、后面是反弹还是反转。

短句一条一条给。作者的私人口径要留（"指数波动不超 2% 就不叫大跌"），这类标准比结论更有用。

### 二、方向

作者给了几个就写几个，每个一个短段，段内写清：是什么、适合谁、难点在哪。

并列项多的时候用序号，一项一行：

```
1、小市值加大容量，主线，但难度最大。
2、抄社保三季度的新加仓，稳，但慢。
3、AI 应用端细分，资金在往小的地方走。
```

**作者明确反对的，单独成段，用「注意：」或「重点：」打头。** 这是全文最值钱的信息。

```
注意：高股息不要再追了。很多卖方报告现在都在推高股息，他的看法正好相反。
```

### 三、位置和节奏

现在能不能动手、等什么信号、哪个时间窗更重要。

条件判断必须保留条件："如果出现加速下跌，反而是可以动手的位置"——不能写成"可以动手"。

### 收尾

一句话，最好是纪律不是祝福。

```
别急着抄底，也别急着割。等那根右侧阳线。
```

## MD 版（仅公众号 / 第三方排版器）

用户明确说要发公众号时才用：

```
## 一、小标题

段落。

- 无序项
- 无序项

1. 有序项
2. 有序项

**加粗的重点句**
```

仍禁表格、禁 `---`、禁代码块。

## 发布前最后一步

把正文粘进纯文本编辑器或抖音编辑器：

- 搜 `#`、`-`、`*`、`>`、`|`、`---`，直贴版应为零
- 有没有超过 3 行的段落
- 小标题前后有没有空行
- 首屏能不能看到结论

四项都过才算完成。
