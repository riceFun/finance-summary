# 输出模板（抖音文章 / 公众号版）

成品是**一篇能直接粘贴发布的短文章**，700 字上下，手机上一屏半读完。

## 骨架

```
标题（≤20 字，最好带数字或结论）

开头：2~3 句，第一句就是结论。

一、小标题

短段。
短段。

二、小标题

短段。
短段。

三、小标题

短段。

结尾：一句纪律或提醒。
```

节数 **3 节最稳，最多 4 节**。每节 3~5 个短段。

## 标题

固定为：

```
YYYY/MM/DD <主讲人>直播总结：<一句核心结论>
```

日期格式 `yyyy/MM/dd`。日期未给按上下文推断。主讲人未知用频道名。

例：`2026/11/03 祝超直播总结：不再悲观，等一根右侧阳线`

## 各节写法

### 开头（30 字内出结论）

不要写"最近市场震荡加剧"这种铺垫。直接给立场，第二句补位置感。

> 政策底已到，市场底还没确认。这个位置我不悲观了。
> 现在的市场很像 7 月 24 号那一周，主跌段差不多走完了。

### 一、先给整体判断

讲清三件事：现在处在什么位置、凭什么这么判断、后面是反弹还是反转。

用短句一条一条说，不写复合句。作者的私人口径要留（"指数波动不超 2% 就不叫大跌"），这类标准比结论更有用。

### 二、方向（编号框架放这一节）

作者给了几个就写几个，每个方向一个短段，段内写清：是什么、适合谁、难点在哪。

反例（太干）：

> 三个方向：小市值、社保加仓、AI 应用。

正例：

> 第一个方向是小市值加大容量，这是主线，也是最难的，拼手速、拼交易能力。不会选股，就买对应的指数基金做定投。

**作者明确反对的东西，单独一段，前面加粗。** 这是全文最值钱的信息。

> **高股息我不建议再追了。** 现在很多卖方报告都在推高股息，我的看法跟他们相反。

### 三、位置和节奏

写清：现在能不能动手、等什么信号、哪个时间窗更重要。

条件判断必须保留条件："如果出现加速下跌，反而是可以动手的位置"——不能写成"可以动手"。

### 结尾

一句话，最好是纪律不是祝福。

> 这个位置别急着止损，也别盲目抄底。等那根右侧阳线出来再说。

## 改写示例

### 反例：会议纪要体（不要这样）

原来的写法长这样，一条一条列结构、现状、判断，还带表格。信息是全的，但读者读不进去，而且表格贴到抖音里全是竖线符号。

### 正例：手机可读体（要这样）

```
一、三种底部结构，已经走完两种

第一种是改规则，也就是改制度，组合拳已经出来了。

第二种是真金白银，资金也来了，只是力度还不够。

他提到后面肯定还有后手工具，但讲到第三层就收住了，没展开。

所以他的结论是：这里大概率是阶段性反弹，中期低点可能还不在这。
```

同样信息，读者一遍能过。

## 篇幅分配（700 字参考）

- 标题 + 开头：80 字
- 整体判断：180 字
- 方向：280 字
- 节奏：100 字
- 结尾：40 字

任何一节超了，先砍形容词和重复安抚，再砍"看不懂的细节"。

## 发布前最后一步

把正文粘进纯文本编辑器（或抖音编辑器）预览一遍：

- 有没有残留的 `|`、`>`、`---`、`*`
- 有没有超过 3 行的段落
- 首屏能不能看到结论

三项都过，才算完成。
