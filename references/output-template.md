# 输出模板

标准结构如下。**节的顺序固定**，因为顺序本身就是读者的决策链：先知道立场 → 再知道为什么 → 再知道做什么 → 最后知道别做什么。

```markdown
# YYYY/MM/DD <主讲人> 直播总结

## 核心定调

**<一句话立场>。** <补充一句适用范围或前提。>

- <支撑定调的第一条硬事实>
- <第二条>
- <位置类比或时间锚点>

## <编号框架一：如「三种底部结构」>

<一句总判断。>

| 维度 | 现状 |
|---|---|
| <项 1> | <状态/进展> |
| <项 2> | <状态/进展> |

> <若作者有明确结论，用引用块强调。>

## <编号框架二：如「三个方向」>

1. **<方向名>** —— <一句话定义>。<适合谁 / 为什么>。<难点或前提>。
2. **<方向名>** —— ...
3. **<方向名>** —— ...

> 明确反对：**<作者点名否定的方向>。** <作者给出的反差理由>

## 操作节奏

- <已发生的动作>（如：上午 10 点已提示可低吸）
- **<最稳的做法>**：<条件 + 信号>
- <时间窗>
- <当前位置的性质：左侧观察区 / 右侧确认区>

## 板块判断

- **<板块>**：<方向 + 理由>。
- **<板块>**：<方向 + 理由，含"持续性存疑"这类置信度词>。

## 风险提示 / 心态

- **<红线一>** —— <理由>
- <对某种操作的反对，及其代价>
- <心态校正>
```

## 各节写法要点

### 核心定调

- 第一句必须是**立场**，不是"作者认为市场……"这种转述壳。
- 加粗整个立场短语。
- 3~4 条 bullet 支撑，每条一个事实，不写复合句。

### 编号框架表

- 作者**说了几项就几项**，缺项写「未展开」，绝不省略表格行。
- 「现状」列写**进展程度**（已出 / 已开始但不够 / 未动），不写评价。

### 三个方向 / 资产方向

- 每个方向必须四件套：**是什么、为什么、适合谁、难点**。
- 只写"关注 AI 应用"是废信息；写"AI 应用端细分，因为资金在往小的地方走，适合会选股的人，难点是分辨真需求"才有用。
- 明确反对项单独用引用块，这是作者立场差异化最强的地方。

### 操作节奏

- 把「如果 A 就 B」完整保留，不写成「要 B」。
- 区分三种时态：**已经提示过的** / **现在可以做的** / **要等信号才做的**。
- "左侧 / 右侧"这类术语直接沿用，不要翻译成"早一点/晚一点"。

### 板块判断

- 用「方向 + 置信度」双要素。作者的犹豫（"打问号""需要时间""先等一等"）是核心信息，不可抹平成看多/看空。
- 不懂的、作者自己说看不懂的板块，如实写"作者表示看不懂"。

### 风险提示 / 心态

- 优先收录**否定式红线**（"不要止损""不要追高股息""不要盲目抄底"），比看多推荐更有行动价值。

## 标题与元信息

- 标题：`# YYYY/MM/DD <主讲人> 直播总结`
- 主讲人未知 → 用频道名或「某分析师」，不要留空。
- 日期未知 → 用内容推断并在标题下加一行 `> 日期依据正文线索推断：<线索>`。

## 长度参考

| 原稿字数 | 目标产出 |
|---|---|
| 3k~5k | 600~900 字 |
| 5k~10k | 900~1400 字 |
| 10k+ | 1400~2000 字，可分场次（早盘/午盘/收评） |

框架性内容（编号方向、底部结构、时间窗）**不受字数限制**，宁可超也不压。
